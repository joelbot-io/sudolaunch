🛡️ Execution Modes & UAC Elevation (Ctrl+Enter)

SudoLaunch provides instant keyboard control over whether commands execute in your interactive PowerShell session or with full Windows Administrator privileges:

Enter Visible Terminal Execution

Runs custom PowerShell commands and scripts visibly inside SudoLaunch's persistent PowerShell session (node-pty + xterm.js) with full ANSI color and scrollback.

Ctrl+Enter Elevated "Sudo" Mode

Elevates any command via Windows User Account Control (UAC) using Start-Process powershell.exe -Verb RunAs with a safely Base64-encoded -EncodedCommand payload.

🔍 Unprefixed Universal Search

Typing without a leading slash (e.g. chrome, docker) automatically fans out across contacts, snippets, installed apps, open windows, and custom commands.

🧰 System Management Control Center (/system)

Click the 🧰 icon on the Dock or run /system (alias: /sys) to open the 7-category workstation management suite:

1. 🪽 WinGet & Windows Update

Inspect outdated packages, batch upgrade/pin/uninstall, browse winget show version drawers, check global npm/pip/WSL updates, export JSON snapshots, and check all 4 Windows Pending Reboot registry keys + KB hotfixes.

2. ⏰ Cron & Scheduled Jobs

Dedicated top-level tab right next to System Updates for scheduling PowerShell/Python scripts, custom commands, and maintenance routines via 5-field cron expressions or system events.

3. 🛠️ Runtimes, PATH & Env Vars

Audits 12 developer toolchains (node, python, uv, go, pwsh, git, dotnet, rustc, docker) with where.exe PATH shadowing detection, broken PATH doctor, and a Registry Environment Variable editor with secret masking.

4. ⚙️ Services, Startup & Tasks

Pin favorite Windows Services (Docker, ssh-agent, WslService) with UAC Start/Stop/Restart, inspect login startup entries, and manage Windows Task Scheduler jobs.

5. 🔌 Ports, Hosts & Quick DNS

Inspect listening TCP ports with one-click firewall rules or PID kill, toggle C:\Windows\System32\drivers\etc\hosts mappings in-place, and switch adapter DNS between Cloudflare (1.1.1.1), Google (8.8.8.8), Quad9 (9.9.9.9), or DHCP.

6. 🧹 Cache, SMART & Power/Repair

Reclaim space across WinGet, npm, Go, pip, uv, CrashDumps, and Temp caches; inspect NVMe/SSD SMART health; switch Windows power plans; and run wsl --shutdown, sfc /scannow, or DISM repairs.

7. 🛡️ Defender, BitLocker & Events

Audit Windows Defender status, manage workspace folder exclusions (ExclusionPath) via UAC, inspect BitLocker volume protection, and triage Windows Event Log Critical/Error stack traces.

⏰ In-App Cron & Scheduled Jobs (/jobs & ⏰ Dock Module)

Click the ⏰ icon on the Dock, select the ⏰ Cron & Jobs tab in the System Management window, or run /jobs (aliases: /sched, /schedule) to run automated background jobs without touching Windows Task Scheduler.

  • Zero-Polling Single-Timer Engine: Calculates the exact millisecond delta to the earliest upcoming nextRunAt across all active schedules and arms a single setTimeout — zero background CPU polling.
  • 6 Trigger Types:
    • cron: Standard 5-field cron expressions (e.g. 0 9 * * 1-5, */15 * * * *) with live plain-English explanations and next-run previews.
    • interval: Fixed repeating interval in minutes.
    • startup: Runs once automatically after SudoLaunch starts.
    • unlock / resume / network-change: Event-driven triggers powered by Electron's powerMonitor and network interface monitoring.
  • 4 Action Types: Run any .ps1 / .py / .cmd script file, inline PowerShell snippet, SudoLaunch custom command, or built-in profile maintenance script (e.g. automatic daily profile backups).
  • Declarative Sync in Custom Commands: Add "Schedule": "0 9 * * 1-5" or "IntervalMinutes": 60 directly inside any ~/.sudolaunch/commands/*.json file to automatically register and sync a scheduled job.

🔀 Git Repository Switcher & File Watchers (/repo & F9)

Press F9, click the 🔀 Dock icon, or run /repo to manage active Git repositories and live file watchers:

  • Single-Spawn Status & Branch Switcher: Queries branch name, dirty file count (*), and ahead/behind counts in a single fast git status --porcelain=v1 -b call, with instant branch switching, branch creation, Pull, Push, and Fetch.
  • Live Chokidar File Watchers (git-watchers.json): Attach glob watchers (e.g. src/**/*.{ts,tsx}) with configurable debounce and cooldown timers to automatically trigger npm run scripts or Git sync commands when files are saved.

⌨️ Customizable Shortcuts Overlay (/shortcuts & ⌨️ Dock Module)

Click the ⌨️ Dock icon or run /shortcuts (aliases: /sc, /hotkeys) to toggle a draggable, resizable, always-on-top frosted-glass shortcut deck:

  • 6 Built-In Tabs + Unlimited Custom Tabs: ⭐ Favorites, 🧰 PowerToys (20+ tools), 🐳 Docker (19 CLI actions + live Container Control Center), 🪟 Windows, 💻 Dev & Git, and ⚡ Custom.
  • 6 Click-to-Execute Action Modes: Hardware keystroke injection via resources/bin/sendkey.exe, PowerToys direct launch, SudoLaunch Terminal execution, background/elevated PowerShell, URL/app launch, or SudoLaunch palette commands.
  • Live Key Recorder (🎹 Record Keys): Create custom shortcuts or override built-in cards by pressing any key combination directly in the modal.

>_ Persistent Drop-Down PowerShell Terminal (/term)

Powered by node-pty + xterm.js with 8ms frame-coalesced rendering for zero-flicker high-throughput output:

  • Global Triggers: Press Ctrl+Alt+T (configurable), Ctrl+Win+/, or F1 from any application to drop down your persistent PowerShell console.
  • Direct Execution: Run /term <command> from the palette to expand the console and execute immediately while preserving shell state and history.

⇄ Network Input Sharing (/control)

Share your local keyboard and mouse across multiple Windows machines running SudoLaunch over mutual TLS (mTLS):

  • Pinned TLS Fingerprints: Every machine generates a persistent self-signed identity certificate in ~/.sudolaunch/control-identity.{key,crt}. Connections are only accepted when the peer's SHA-256 certificate fingerprint matches peers.json.
  • Instant Safety Escape: Press ScrollLock, Pause/Break, or Ctrl+Alt+S at any time to immediately release remote capture and return control to your host PC.

📜 Custom Commands & Script Browsers

Drop JSON files into %USERPROFILE%\.sudolaunch\commands\ to register custom /<name> commands with named parameters, optional cron schedules, or interactive .ps1 / .py folder browsers:

~/.sudolaunch/commands/deploy.json 
{
  "Command": "deploy",
  "Action": "Write-Host 'Deploying {env}...'; ./scripts/deploy.ps1 -Env {env}",
  "Label": "Deploy Environment",
  "ShowTerminal": true,
  "Schedule": "0 9 * * 1-5",
  "Parameters": [
    { "Name": "env", "Description": "Target environment (staging, prod)" }
  ]
}

⚙️ Configuration Files & Profile Maintenance

All user data lives in %USERPROFILE%\.sudolaunch\ and is watched live via Chokidar for zero-restart editing:

  • settings.json — Global hotkeys, dock layout/glow, home anchor, and module order
  • schedules.json — In-app scheduled jobs, cron triggers, and execution logs
  • git-watchers.json — Per-repository live Chokidar file watcher rules
  • shortcuts.json — Custom shortcut tabs, starred favorites, and key overrides
  • command-layout.json — Palette root order and nested command subfolders
  • contacts.json, snippets.json, links.json, teamLinks.json, peers.json, sshHosts.json

🚀 Setup, Testing & Building Releases

PowerShell — Development, Unit Tests & Packaging 
# 1. Install dependencies (automatically restores prebuilt Windows x64 native modules)
npm install

# 2. Launch in development mode with HMR
npm run dev

# 3. Run TypeScript typechecking & Vitest unit test suite (26 tests)
npm run typecheck
npm test

# 4. Build standalone Windows NSIS installer locally (-> dist/SudoLaunch-0.1.0-setup.exe)
npm run build:win
Automated GitHub Releases: Pushing a version tag matching v* (e.g. git tag v0.1.0 && git push origin v0.1.0) triggers .github/workflows/release.yml to run all tests, compile native helpers, package the Windows NSIS installer, and publish the release assets to GitHub Releases.
